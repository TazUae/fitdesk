# Dashboard Mission

FitDesk Dashboard is not a reporting screen.

FitDesk Dashboard is the Trainer Command Center.

The dashboard must answer:

> What do I need to do right now to run my coaching business?

The dashboard should be:
- Action-first
- Workflow-first
- Trainer-first
- Mobile-first
- AI-assisted
- ERP-authoritative

---

# Core Product Principles

## Action Before Analytics
Show actions before metrics.

## Progressive Disclosure
Level 1: Session ended
Level 2: Completed / No Show / Cancelled / Rescheduled
Level 3: Generate invoice / Mark paid / Send reminder

## Calm Design
Inspired by Linear, Notion, Stripe, Ramp, Apple Fitness.

## Trainer Speed
Primary actions reachable in one click desktop, one tap mobile.

## AI Philosophy
AI Copilot, not AI Chatbot.
AI suggests. Trainer decides.

# Needs Attention

Transactional and urgent.

Includes:
- Session Outcomes
- Client Communications
- Missing Next Session
- Overdue Payments

## Session Outcome Workflow

Completed:
- Package Client → decrement package balance
- Pay Per Session → generate invoice

No Show:
- Package Client → Deduct session? Yes/No
- Pay Per Session → Charge missed session? Yes/No
